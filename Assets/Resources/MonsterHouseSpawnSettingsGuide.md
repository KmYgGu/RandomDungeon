# 몬스터 하우스 생성 확률 설정

Unity Project 창에서 같은 폴더의 `MonsterHouseSpawnSettings.asset`을 선택해 Inspector에서 수정합니다. 자동으로 적용되므로 씬에 연결하지 않아도 됩니다.

- `Default Chance`: 적용되는 층 항목이 없을 때의 확률.
- `Stages > From Stage`: 이 설정을 적용하기 시작할 층 번호.
- `Stages > Chance`: 확률. 0은 0%, 0.5는 50%, 1은 100%입니다.

각 항목은 다음 시작 층 직전까지 적용됩니다. 예: 1층 0.2 / 5층 0.4 / 10층 0.1이면 1~4층 20%, 5~9층 40%, 10층 이후 10%입니다. 매 층 항목을 만들면 층마다 따로 조절할 수 있습니다. 항목 순서는 무관하며 같은 시작 층을 중복 입력하면 뒤 항목이 우선합니다.

기본값은 기존 확률을 유지하도록 1~20층 항목을 제공하며, 이후는 20층 확률을 유지합니다. 변경은 다음 던전 생성부터 적용됩니다. 방이 3개 미만이거나 생성 실패 시 사용하는 대체 던전에는 하우스가 없습니다.

하우스도 다른 방처럼 플레이어 시작 방으로 선택될 수 있습니다. 시작 방이 하우스면 첫 입력 전에 등장 연출을 진행하고 플레이어 턴으로 넘깁니다.
